# Task Manager

Простий веб-застосунок для ведення списку задач у браузері.
Задачі можна додавати та переглядати у вигляді списку.
Проєкт створено для практичних робіт з дисципліни «Системи керування версіями».

## Встановлення

1. Клонувати репозиторій.
2. Відкрити файл index.html у браузері.

## Структура проєкту

- index.html - головна сторінка
- src/app.js - логіка роботи зі списком задач
